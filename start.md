# claude-toolkit - точка входа

Этот файл - точка входа в репозиторий `claude-toolkit`. Если пользователь сказал "выполни инструкции из `<...>/start.md`", это значит, что он хочет либо настроить новый проект, либо синхронизировать уже настроенный с каноном. Твоя задача - спросить, что именно, и направить в нужный промт.

## Определи canon_base

Источник этого файла - URL или локальный путь - определяет базу:

- HTTP: `<canon_base>` = директория этого файла. Пример: загружен по `https://raw.githubusercontent.com/dewil/claude-toolkit/main/start.md` -> `<canon_base> = https://raw.githubusercontent.com/dewil/claude-toolkit/main`.
- Локально: `<canon_base>` = `dirname(этот файл)`. Пример: `~/Work/claude-toolkit/start.md` -> `<canon_base> = ~/Work/claude-toolkit`.

Все остальные файлы репо адресуются относительно `<canon_base>`:

- `<canon_base>/bootstrap/bootstrap-01-memory.prompt.md`
- `<canon_base>/bootstrap/bootstrap-02-scaffold.prompt.md`
- `<canon_base>/bootstrap/bootstrap-03-<тип>.prompt.md`
- `<canon_base>/rules/*.md`
- `<canon_base>/agents/*.md`
- `<canon_base>/skills/<name>/*`
- `<canon_base>/migrations/*.prompt.md`
- `<canon_base>/manifest.yaml`

## Что в этом репо

- `bootstrap/` - цепочка для настройки проекта с нуля (01-memory -> 02-scaffold -> 03-<тип>).
- `rules/` - канонические правила поведения Claude.
- `agents/` - канонические описания субагентов.
- `skills/` - канонические скиллы (папка на скилл).
- `migrations/` - промты для синхронизации существующих проектов с каноном (`sync-from-canon.prompt.md`).
- `manifest.yaml` - полный список канон-файлов по типам (используется sync для autodiscovery).
- `CLAUDE.md` - архитектурный контекст для Claude, работающего ВНУТРИ этого репо.

## Спроси у пользователя, что делаем

Одной строкой:

> Что делаем? 1) новый проект (bootstrap с нуля) 2) синк существующего проекта с canon 3) ничего, просто посмотреть

Маппинг ответа -> действие:

### 1) Новый проект

- Загрузи `<canon_base>/bootstrap/bootstrap-01-memory.prompt.md` (по HTTP - WebFetch, локально - Read).
- Содержимое - инструкции для тебя. Выполни как продолжение текущей сессии. Дальше цепочка сама проведет через 02-scaffold и 03-<тип>.

### 2) Синк существующего проекта

- Загрузи `<canon_base>/migrations/sync-from-canon.prompt.md` (по HTTP - WebFetch, локально - Read).
- Содержимое - инструкции для тебя. Выполни как продолжение текущей сессии.

### 3) Ничего

- Опиши кратко состав репо (список выше) и остановись.

## Принципы (общие для всех промтов репо)

- **Идемпотентность.** Любой промт безопасен при повторном запуске. На свежем/актуальном проекте отрабатывает как no-op.
- **Audit -> plan -> "ок" -> action.** Любая правка делается только после явного подтверждения. Без "ок" - только чтение.
- **Изоляция.** Проект ничего не знает о filesystem-расположении локального клона claude-toolkit. Все - через HTTP или через самодостаточные артефакты.
- **Канон в одном экземпляре.** Правила и агенты живут только в `rules/`/`agents/` репо, не дублируются heredoc'ом в bootstrap-промтах.
- **Русская типографика.** Кавычки `"..."`, тире и дефис - один и тот же символ `-`, "е" вместо "ё". См. `rules/typography-ru.md`.
