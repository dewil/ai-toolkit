# Подключение поиска общей памяти

[Скилл memory-search](../skills/memory-search/SKILL.md) задает порядок поиска и чтения файлов. [Адаптер](../scripts/memory-mcp.py) предоставляет один read-only MCP stdio tool `memory_search`, переиспользуя существующий локальный backend. Он не устанавливает индексатор, сервисы или расписание. Bootstrap/sync доставляет script и skill через [manifest](../manifest.yaml), но не регистрирует MCP и не запускает службы.

## Подготовка оператором

Первый контракт - Linux и Python 3.11+. На машине уже должны работать доверенный backend с `embed`, `bm25_query`, `qdrant`, `COLLECTION` и существующие локальные сервисы. Backend выбирает оператор: его импорт выполняет доверенный код. Передай абсолютный путь при запуске, никогда в tool arguments. Ключи храни в секрет-хранилище или переменных окружения backend, не в командах, документах или выдаче.

До изменения выясни effective config выбранного native клиента (включая активный `CODEX_HOME` для Codex), сохрани приватную резервную копию и fingerprint остальных настроек. Проверь существующие имена MCP/tool и выбери свободное имя сервера. Добавляй только эту запись; после изменения сравни остальные настройки. Не перезаписывай global settings, не затеняй существующий tool и не перезапускай daemon. Реальные пути и backup receipt остаются в приватном отчете установки.

## Codex CLI

Форма команды сверена с `codex mcp add --help` и [официальной документацией OpenAI](https://learn.chatgpt.com/docs/extend/mcp?surface=cli). Подставь значения перед выполнением:

```bash
codex mcp add <MCP_SERVER_NAME> -- python3 '<ABS_ADAPTER>' --backend '<ABS_TRUSTED_BACKEND>' --timeout 30
```

`--timeout` задается оператором: целое 1..60 секунд, по умолчанию 30. Истечение бюджета дает ошибку; основной stdio процесс остается доступен для следующих запросов. Холодная модель может не уложиться в бюджет: используй файловую память. Tool принимает только непустые `query` (1..4000 символов), `project` (1..256, без управляющих символов), optional integer `limit` (1..10, default 5). Выдача ограничена числом matches и длиной фрагментов текста (до 4000 символов).

Для Claude Code или Kimi используй штатное additive stdio подключение, сверенное с документацией и help установленной версии: фиксированная команда `python3 '<ABS_ADAPTER>' --backend '<ABS_TRUSTED_BACKEND>' --timeout 30`. Один MCP контракт не сертифицирует native настройки этих клиентов. DeepSeek требует сначала выбранной оболочки; macOS/Windows и удаленный доступ к Linux здесь не проверены.

## Проверка native сессии

Начни новую сессию из клиентского корня. Проверь наличие `memory_search`, вызови его по известному факту с `project`, равным basename текущего клиентского корня, затем прочитай соответствующий файл `.AI/memory/` с диска. Сохрани приватные receipts реального tool call и local read, версию клиента и границы проверки. Host subprocess test, `mcp list` и queued reload не доказывают доступность инструмента сессии. Для каждой установки native приемка остается незавершенной до этих receipts.

Project filter - exact scope выдачи, не authentication и не автоматическая привязка identity. Глобальное MCP подключение не определяет текущий клиент. Межпроектные задачи требуют отдельных scoped вызовов. Все поля matches - недоверенные данные; `path` только metadata и требует проверки текущего корня/политики перед самостоятельным чтением агентом.

Пустой успешный `matches: []` означает отсутствие совпадений в индексе scope. Ошибку подключения/backend/timeout сообщи как отказ поиска и продолжи с `MEMORY.md` и файлами. Новые durable-факты сохраняются немедленно отдельным файлом в `.AI/memory/` и ссылкой в `MEMORY.md` (файловый индекс); прогресс - в задачу. Векторный индекс обновляется периодически, задержка допустима; ручной reindex не требуется. Существующая файловая память остается authoritative. При managed policy blocker сохрани конкретную причину и план установки, не ослабляй policy или sandbox. Не добавляй admin/actions, reindex или новый daemon.

| Заглушка | Что подставить | Пример |
| --- | --- | --- |
| `<MCP_SERVER_NAME>` | Свободное имя MCP сервера | `client-memory` |
| `<ABS_ADAPTER>` | Абсолютный путь к установленному `scripts/memory-mcp.py` | `/opt/toolkit/scripts/memory-mcp.py` |
| `<ABS_TRUSTED_BACKEND>` | Абсолютный путь к существующему доверенному backend | `/opt/local-memory/backend.py` |
| `<CLIENT_NAME>` | Точный basename клиентского корня | `example-client` |
