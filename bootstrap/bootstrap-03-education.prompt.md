# Промт: scaffold для учебных проектов

Этот файл - инструкция для Claude Code. Запускать **после** `bootstrap-02-scaffold.prompt.md`: открой Claude Code в **корне проекта** и попроси выполнить этот файл (например: `выполни инструкции из <путь>/bootstrap-03-education.prompt.md`).

Промт безопасен для существующих проектов. Сначала аудит, действия - после "ок". Существующие файлы не перезаписываются.

Для проектов учебных курсов: AI помогает вести конспекты по транскриптам лекций, разбираться с домашками, готовиться к экзаменам.

Добавляет к общему scaffold:

- агента `note-taker` (конспект из стенограммы)
- правила: `lecture-notes.md`, `homework.md`, `course-structure.md`
- папки: `Лекции/`, `Конспекты/`, `Домашки/`, `Источники/`
- `@-`ссылки на новые правила в `CLAUDE.md`
- (опционально, по согласию) скилл `tutor` - сократовский репетитор для живого диалога с учеником: ведет к ответу вопросами, по одному, не решает за него. Предмет, уровень и формат скилл выясняет в начале сессии, объемную предметику берет из проектного файла-справочника.

КОНТЕКСТ ЦЕПОЧКИ. Это шаг 03. **Источник этого файла** (всегда HTTP-URL) определяет базу для канонических файлов:

- `canon_base` = подняться на один уровень из `bootstrap/`. Например, если этот файл загружен по URL `.../main/bootstrap/bootstrap-03-education.prompt.md`, то `canon_base = .../main/`.
- Канонические агенты и правила специализации: `<canon_base>/agents/*.md`, `<canon_base>/rules/*.md`.
- Предыдущий шаг (сиблинг): `bootstrap-02-scaffold.prompt.md` в той же папке.

**Канон только по HTTP.** `<canon_base>` - всегда HTTP-URL; канон тяни исключительно по HTTP. Локальный клон claude-toolkit на машине (даже соседней папкой с проектом) не ищи и не подхватывай. Это держит изоляцию: раскатывается закоммиченный `main`, не чужое рабочее дерево.

- Перечисли существующие:
  - какие файлы секции `education` уже есть в проекте (по generic-маппингу: `rules/*` -> `.claude/rules/*`, `agents/*` -> `.claude/agents/*`, `skills/<name>/...` -> `.claude/skills/<name>/...`)
  - .claude/canon.yaml - есть ли (должен быть после bootstrap-02), что в `files` и `file_hashes`
  - CLAUDE.md - какие @-ссылки уже есть
  - Папки Лекции/, Конспекты/, Домашки/, Источники/
  - Если в Лекции/ или Конспекты/ что-то есть - посмотри top-3 файла, чтобы понять формат, и сообщи. Не правь.

ШАГ 2. Целевое состояние.

A. Канонический набор education = секция `education` в `manifest.yaml` (правила + агенты + скиллы специализации). Источник истины списка - **только манифест**; здесь файлы поименно не перечисляем. На ШАГ 4 фетчнешь манифест и раскатаешь секцию `education` по generic-маппингу: `rules/<name>.md` -> `.claude/rules/<name>.md` (+ @-импорт); `agents/<name>.md` -> `.claude/agents/<name>.md`; `skills/<name>/...` -> `.claude/skills/<name>/...` (скилл - папка, копируются все ее файлы из секции); `scripts/<name>` -> `<name>` в корне + `chmod +x`.

B. CLAUDE.md содержит `@`-ссылку на каждое правило `rules/*` из секции `education`.

C. Папки в корне: Лекции/, Конспекты/, Домашки/, Источники/.

D. `.claude/canon.yaml`:
   - `files` дополнен всеми путями секции `education`, которых там еще нет; + `skills/tutor/SKILL.md`, если на E согласились.
   - `file_hashes` дополнен sha256 раскатанных файлов.
   - `project_type` - список, и `education` в нем (если списка нет/пустой - инициализируется на ШАГ 4; если `education` отсутствует среди других типов - добавляется на ШАГ 4).

E. (Опционально, по согласию) `.claude/skills/tutor/SKILL.md` - сократовский скилл-репетитор. Спроси меня, нужен ли он этому курсу. Если да - скопируется на ШАГ 4 и добавится в `canon.yaml -> files`. Если нет - пропускается и в `canon.yaml` не заносится (на следующем синке autodiscovery предложит его снова).

ШАГ 4. Действуй (после "ок").

### 4a. Раскатай секцию `education` манифеста

1. Возьми секцию `education` манифеста, полученного в ШАГ 1.
2. Для каждого файла секции, которого еще нет в проекте (локальный путь - по generic-маппингу из ШАГ 2 A):
   - получи канонические байты **точными байтами** (`curl -fsSL <canon_base>/<path>`; не `WebFetch` - он лоссовый, ломает sha256 и корежит `.py`);
   - запиши в локальный путь; для `scripts/` поставь `chmod +x`;
   - посчитай sha256 записанных байт (`shasum -a 256 <локальный путь> | awk '{print $1}'`, на Linux - `sha256sum`) - база снимка для `file_hashes` в 4b.

Существующие файлы НЕ перезаписываются (для них хеш не пишем - база определится на первом синке). Для апгрейда к актуальной версии канона есть `migrations/sync-from-canon.prompt.md`.

### 4b. Создай папки (если отсутствуют)

`Лекции/`, `Конспекты/`, `Домашки/`, `Источники/` с `.gitkeep` в каждой.

### 4c. Допиши `.claude/canon.yaml`

- В `files` добавь все пути секции `education`, которых там еще нет (в каноническом виде, без `.claude/`-префикса).
- В `file_hashes` добавь sha256 (из 4a) для файлов, которые реально записал; для уже существовавших файлов запись не добавляй. Если секции `file_hashes` в файле еще нет - заведи ее.

Правь точечно, не пересоздавая файл. Если `canon.yaml` нет - значит bootstrap-02 не выполнялся; сообщи об этом и не создавай `canon.yaml` сам (это работа шага 02).

Отдельно про `project_type` (всегда **список**):

- Если поля нет вообще или это пустой список `[]` - инициализируй `project_type: [education]`.
- Если поле уже содержит `education` - не трогай (идемпотентность).
- Если поле содержит другие типы, но без `education` - **добавь** `education` в конец списка. Это нормальный случай мультиспециализации; не "миграция типа", не спрашивай - добавляй.
- Если поле - скаляр-строка (старый формат до перехода на список) - перепиши в список и добавь `education`. Сообщи в отчете о миграции формата.

### 4d. Дополни существующие файлы

Дополнения CLAUDE.md (по `@`-ссылке на каждое правило `rules/*` секции `education`, которого еще нет в CLAUDE.md) - по отдельному "ок".

### 4e. (Опционально) Скилл-репетитор `tutor`

Только если я согласился на ШАГ 2 (E). Скилл `tutor` - папка; все его файлы уже в секции `education` манифеста и будут скопированы на 4a. Убедись, что `.claude/skills/tutor/` создана и `SKILL.md` на месте. Существующий файл НЕ перезаписывай. Если я отказался - исключи файлы `skills/tutor/*` из раскатки на 4a и не добавляй их в `canon.yaml`.
