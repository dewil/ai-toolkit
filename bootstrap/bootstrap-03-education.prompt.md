# Промт: scaffold для учебных проектов

Этот файл - инструкция для Claude Code. Запускать **после** `bootstrap-02-scaffold-common.prompt.md`: открой Claude Code в **корне проекта** и попроси выполнить этот файл (например: `выполни инструкции из <путь>/bootstrap-03-education.prompt.md`).

Для проектов учебных курсов: AI помогает вести конспекты по транскриптам лекций, разбираться с домашками, готовиться к экзаменам.

Промт безопасен для существующих проектов. Сначала аудит, действия - после "ок". Существующие файлы не перезаписываются.

Добавляет к общему scaffold:

- агентов: `note-taker`, `tutor`
- правила: `lecture-notes.md`, `homework.md`, `course-structure.md`
- папки: `Лекции/`, `Конспекты/`, `Домашки/`, `Источники/`
- `@-`ссылки на новые правила в `CLAUDE.md`

Общие агенты `summarizer` и `planner` приходят из `bootstrap-02-scaffold-common.prompt.md` и здесь не дублируются.

# Конспекты лекций

## Именование файлов

`Конспекты/<NN>-<короткая-тема>.md`, где NN - номер лекции в курсе.

Примеры:
- `Конспекты/01-introduction.md`
- `Конспекты/07-recursion.md`

Стенограммы - в `Лекции/<NN>-<тема>/transcript.md`.

## Обязательные секции конспекта

```markdown
# Лекция NN: <тема>

**Дата:** YYYY-MM-DD
**Лектор:** <имя>
**Источник:** Лекции/NN-<тема>/transcript.md

## Ключевые идеи

- Идея 1.
- Идея 2.

## Термины

- **Термин**: определение.

## Формулы / примеры

(только если были в лекции)

## Связи с другими темами

- См. также: [Лекция MM](./MM-<тема>.md).

## Открытые вопросы

- Что не понял.
- Что лектор обещал разобрать позже.

## Дополнительные материалы

- Книги/статьи/видео, упомянутые лектором.
```

## Правила

- Конспект - по источнику. Не добавляй идеи, которых не было в лекции, без явной пометки "(моя интерпретация)".
- Если стенограмма пустая или ее нет - создавай конспект по своим заметкам, но в "Источник:" укажи "конспект слушателя".
- Не редактируй конспекты прошлых лекций при изучении новой - связи и уточнения добавляй в "Связи с другими темами".

# Домашние задания

## Принципы AI-помощи

- Цель - научиться, а не сдать. AI помогает разобраться, но не пишет решение за студента.
- Сначала AI спрашивает, что студент уже понял и где застрял.
- AI дает наводящие вопросы, объясняет концепт, показывает похожие примеры.
- Готовое решение AI показывает только по явной просьбе ("покажи решение целиком") - и после показа объясняет каждый шаг.
- При проверке решения AI указывает, где ошибка и какой принцип нарушен; не молча исправляет.

## Структура папки задания

`Домашки/<NN>-<короткая-тема>/`

```text
Домашки/01-loops/
├── task.md          # Условие задачи (можно копию из учебника)
├── attempt.md       # Что студент пробовал, где застрял
├── solution.md      # Финальное решение (после понимания)
├── notes.md         # Что узнал нового, что было сложно
└── src/             # Код, если задача программистская
```

## Правила ведения

- `attempt.md` ведется ДО `solution.md`. Если идешь сразу в solution - ты не учишься, а копируешь.
- `notes.md` пишется в конце; что застряло, какой концепт оказался ключевым.
- При сдаче - проверь, что решение твое (не сгенерированное), и что ты можешь его объяснить.

# Структура учебного курса

```text
.
├── Лекции/                # Стенограммы лекций
│   └── NN-<тема>/
│       ├── transcript.md    # Стенограмма
│       └── slides/          # Слайды (если есть)
├── Конспекты/                   # Конспекты (см. lecture-notes.md)
│   └── NN-<тема>.md
├── Домашки/                # Домашние задания (см. homework.md)
│   └── NN-<тема>/
├── Источники/              # Книги, статьи, ссылки, шпаргалки
│   ├── books.md
│   └── links.md
└── docs/                    # Постоянная общая документация
    └── syllabus.md          # Программа курса, дедлайны, требования
```

## Правила

- Один курс - один проект. Если несколько курсов - разные репо или подпапки `<курс>/`.
- Стенограммы не редактируются - только конспекты.
- `Источники/` пополняется по мере того, как лектор упоминает источники.
- Финальные проекты/работы - в `Домашки/final/` или `final-project/`.
