# Компактный результат по умолчанию

Рутинные проверки отдавать в чат компактно. Развернутый вывод - только когда есть что чинить. Цель - беречь токены основного контекста на повторяющихся операциях.

## Принцип

- **Прошло** - одна строка с итогом: `тесты: 12/12 ok`, `lint ok`, `build ok`, `деплой ok`, `проверка X: 200 ✓`. Без эха всего лога.
- **Упало** - показать только релевантный кусок: имя упавшей проверки + assert/ошибку/нужную строку вывода. Не весь verbose-лог.

## Где применять

- Тесты (любой раннер) - сводка `N/M ok`, при падении - только упавшие кейсы.
- Линт / типчек / сборка - статус строкой, при ошибке - конкретные сообщения.
- Сетевые проверки (curl, healthcheck) - итог + код ответа, не полный `-v`.
- Деплой - финальный статус, не построчный вывод процесса.
- Удаленные команды (ssh и т.п.) - результат, не эхо самой команды.

## Чего не делать

- Не глушить падающие проверки ради краткости. Краткость - для зеленых прогонов; красные показываем по делу (это не противоречит правилам про покрытие тестами).
- Не вставлять полные дампы (логи, JSON, длинный stdout) в основной чат. Такие выводы - через субагента с возвратом итога в N строк (см. экономию токенов в `subagents-usage.md`).
