# Переносимость агента

Статус задач: `.AI/rules/task-status.md`.
До работы прочитай `.AI/rules/docs-maintenance.md`.

Для `.AI`-проекта: если нет `.AI/project.json`, но есть `.AI` или `.ai-bootstrap` (включая битые ссылки), раскладка повреждена: сохрани файлы и журналы, остановись без legacy fallback, миграции или bootstrap. Если нет и этих путей, сохраняй существующие файлы, память и учет задач без изменений. Старые bootstrap/sync не поддерживаются и из этого правила не запускаются. При явном legacy-маркере остановись и предложи отдельный запрос миграции в `.AI`. У ненастроенного клиента синхронизировать нечего; новый проект устанавливается через `start.md` только по запросу. Не запускай миграцию или bootstrap автоматически.

В начале работы прочитай `.AI/rules/compact-results.md` и постоянно применяй его к ответам, документам, задачам и переписке.

При наличии `.AI/project.json` источник знаний - `.AI/`; корень клиента и project_id общие для подпроектов. Контейнер проектов не является клиентом: не сканируй и не инициализируй его автоматически. Legacy-раскладку сохраняй до отдельной миграции.

После rename новый upstream — `dewil/ai-toolkit`: явно укажи его в следующем обычном sync; origin форков и pin сохрани.

В новой сессии прочитай `.AI/START.md`, `.AI/project.md`, `.AI/memory/MEMORY.md`, текущую задачу и релевантные записи. Применимые правила, навыки и роли из каталога START читай до действия. AGENTS.md и CLAUDE.md генерируются: правь источники, затем выполняй build. Совместимые `.claude/` и `.agents/skills` - ссылки. Обновляй установленный канон навыком `canon-sync` по pinned `migrations/ai-sync.prompt.md`; старые sync, canon-delta/canon-migrate и legacy-bootstrap запрещены. START - управляемый каталог; проектный контекст правь в `.AI/project.md`.

До работы найди существующего или создай Markdown-владельца задачи в проектном бэклоге (по умолчанию `docs/backlog/`). При изменении состояния записывай ID, цель, ограничения, сделанное, проверки, блокеры и следующий шаг. При выполнении критериев готовности перенеси задачу в `docs/done/` с тем же ID.

Для каждой активной задачи обязателен переносимый учет расхода по `rules/task-cost.md` и скиллу `session-cost`. Ledger атомарно пишет один текущий владелец; handoff включает receipts или `unknown`, итог сообщает coverage. Нативная настройка агента этот маршрут не заменяет.

Общая память - `.AI/memory/`; durable-факты сохраняй сразу. Новая `.AI` не подключается к глобальному векторному индексу автоматически. После отдельного подключения работает существующий периодический процесс Linux; задержка допустима. Без индекса работай с файлами и укажи ограничение поиска. Bootstrap не запускает службы и не переносит настройки, разрешения или секреты агента.

Подключение адаптера подтверждай проверкой в новой сессии из корня: вход, project_id, общая память, задача, запись факта и чтение следующей сессией. При обычной установке выполни доступные проверки выбранного текущего агента; остальные адаптеры отметь `NOTRUN`, их проверка установку не блокирует. Заверши установку после успешных `apply`, нужного `build` и `check`. Явно запрошенную многосредную проверку веди отдельной задачей; неисполненное не считай `PASS`. Глобальную нативную автопамять отдельно подключи и проверь; до этого общую память читай и пиши явно. Первый контракт - Linux/Python 3.11+; macOS/Windows не проверены, DeepSeek без выбранной оболочки не поддерживается.
