# Переносимость агента

В `.AI`-проекте действуют требования ниже. Если `.AI/project.json` отсутствует, но `.AI` или `.ai-bootstrap` существуют (включая битые ссылки), считай раскладку поврежденной: сохрани файлы и журналы, остановись без legacy fallback, миграции или bootstrap. Если этих путей нет, сохраняй существующие файлы, память и учет задач без изменений; старые bootstrap/sync-процедуры больше не поддерживаются и из этого правила не запускаются. При явном legacy-маркере остановись и предложи отдельно запросить миграцию в `.AI`. Если клиент еще не настроен, синхронизировать нечего: новый проект можно установить через `start.md` только по запросу. Не запускай миграцию или bootstrap автоматически.

В проекте с `.AI/project.json` источник знаний - `.AI/`; корень клиента и project_id общие для подпроектов. Контейнер рабочих проектов не является клиентом: не сканируй и не инициализируй его автоматически. В legacy-проекте сохраняй раскладку до отдельной миграции.

В новой сессии прочитай `.AI/START.md`, `.AI/project.md`, `.AI/memory/MEMORY.md`, текущую задачу и релевантные записи. Каталог START направляет к установленным правилам, навыкам и ролям; читай применимое до действия. AGENTS.md и CLAUDE.md - генерируемые входы: правь источники, затем выполняй build. Совместимые `.claude/` и `.agents/skills` - ссылки. Обновление установленного канона выполняется общим навыком `canon-sync` по отдельной pinned процедуре `migrations/ai-sync.prompt.md`; `/canon` - тонкий router к нему. Старый sync, canon-delta/canon-migrate и legacy-bootstrap здесь запрещены. START - управляемый каталог, проектный контекст редактируется в `.AI/project.md`.

Каждая задача до выполнения имеет Markdown-владельца в проектном бэклоге (по умолчанию `docs/backlog/`). Записывай ID, цель, ограничения, сделанное, проверки, блокеры, следующий шаг при изменении состояния. Завершай по критериям готовности переносом в `docs/done/` с сохранением ID. Существующего владельца используй повторно.

Общая память - `.AI/memory/`; durable-факты сохраняй сразу. Новая `.AI` автоматически не подключается к глобальному векторному индексу. После отдельного подключения индексация идет существующим периодическим процессом Linux, задержка допустима. Без индекса продолжай файловую работу, укажи ограничение поиска. Bootstrap не запускает службы и не переносит настройки, разрешения или секреты агента.

Каждый адаптер проверяется новой сессией из корня: вход, project_id, общая память, задача, запись и повторное чтение факта. Нативная глобальная автопамять требует отдельного подключения и проверки; до этого общую память читай и пиши явно. Linux/Python 3.11+ - первый контракт; macOS/Windows не проверены, DeepSeek без выбранной оболочки не поддерживается.
