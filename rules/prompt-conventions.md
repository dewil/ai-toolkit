# Конвенции промтов

Применять в проектах, чей артефакт - промты, агенты, правила для Claude.

## Идемпотентность

Любой промт безопасен при повторном запуске. На уже-настроенном проекте отрабатывает как no-op с явным сообщением - не дублирует, не перезаписывает.

## Audit -> plan -> "ок" -> action

Любая правка делается только после явного подтверждения. Без "ок" - только чтение. Промт начинается с шага аудита, за ним план, дальше ждет "ок", только потом действует.

## Sibling-paths без user-asking

Путь к соседнему файлу промт выводит из своего собственного источника (URL или filesystem-путь), не спрашивает у пользователя. Спрашивает только если по выведенному адресу файла физически нет.

## Единый источник

Один артефакт = одна каноническая версия в одном месте. Никаких heredoc-копий канонического контента внутри других промтов. Нужно положить файл - копируй из источника (WebFetch/cp), не встраивай дубль.

## Самодостаточность

Промт не полагается на скрытый контекст и не знает filesystem-расположение машины пользователя. Все нужное - в самом промте либо доступно по явному адресу (URL или путь).
