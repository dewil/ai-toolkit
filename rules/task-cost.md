# Учет расхода задачи

Для каждой активной задачи веди отдельный локальный `<taskID>.usage.json` в устойчивом служебном каталоге задачи вне синка по `rules/docs-maintenance.md`; точный абсолютный путь укажи в Markdown-владельце; checkpoints именуй с task ID, ролью и session ID. Единственный активный владелец задачи атомарно обновляет ledger. Субагенты передают владельцу receipt или явное `unknown`, но не редактируют ledger параллельно. Перед передачей владения зафиксируй handoff в Markdown и дождись остановки прежнего писателя.

Сохраняй исходный checkpoint до начала работы, привязывай отдельные сессии/запросы к задаче и обновляй ledger при вехе, ошибке и handoff. Перед завершением собери доступные receipts, запиши cutoff, собственные дальнейшие токены ответа и недоступные вызовы как `unknown`; не восстанавливай пропущенные цифры догадкой. Неизвестный расход помечается как partial, не блокирует работу и должен быть явно отражен в результате.

До делегирования выбери источник receipt и запиши в handoff. Если уже разрешенный CLI того же provider выдает JSON usage с эквивалентными проверенными правами и возможностями, предпочти его native orchestration без usage; не меняй provider, права или изоляцию автоматически. Codex CLI `exec --json` дает receipt только из явно сохраненного stdout по процедуре `skills/session-cost/task-accounting.md`. Этот режим не ищет native orchestration usage: вызовы без receipt остаются `unknown`, полномерный учет не обещается. Полный `total` при unknown равен null; `measured_total` и `measured_tokens` показывают только подтвержденные цифры, а compact Markdown перечисляет пропуски. Финальная сгруппированная Markdown-таблица имеет поля role, vendor, model, platform, access, tokens, money и coverage (`complete`/`partial`); короткий ответ содержит эту компактную таблицу или ссылку на сохраненную Markdown-таблицу, но не только JSON ledger. Закрывая задачу, перенеси только Markdown-владельца в `docs/done/`; новый служебный ledger и checkpoints остаются по прежнему устойчивому адресу. Старые sidecars не перемещай автоматически; уже закрытые задачи не пересчитывай. Секреты, текст промптов/ответов и транскрипты в ledger не копируй.
