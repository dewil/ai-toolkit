# Проактивная память

Сразу сохраняй решения с причиной, ограничения, поправки, внешние указатели и устойчивое состояние, дорогое для восстановления. В `.AI/memory/` — факт на файл, ссылка в `MEMORY.md`; в legacy — настроенная память. Не сохраняй эфемерное, уже записанное в git и легко выводимое; секреты — заглушкой (`rules/secrets-handling.md`).

## Запись

Найди тот же вопрос в `MEMORY.md`, прочитай сам файл. Новые независимые факты создавай helper'ом:

```bash
python3 scripts/memory-write.py --root "$PROJECT_ROOT" --name short-id \
  --description "Вопрос для поиска" < fact-body.txt
```

stdin — тело, helper создает frontmatter и ссылку. Нужны короткий ASCII ID, `.AI/project.json` и `MEMORY.md`. Linux/flock сериализует helper-записи одного хоста. Перед атомарной заменой сверяются индекс и факт; гонка после сверки остается. Редакторы, Syncthing и удаленные ФС lock не соблюдают. Helper только создает; правка и уплотнение — отдельно, без конкурирующих писателей.

Меняется текущее утверждение — обнови без дубля. Укажи источник и причину, отличай наблюдение от вывода. Важную прежнюю позицию с источником и причиной сохрани как историю или ссылку.

Перед правкой сверь свежую версию; писатель один. При признаках конкурирующей записи или неразобранном расхождении сохрани версии, отложи спорное, запиши шаг в задаче. Syncthing сам по себе не конфликт и не запрет записи.

Не переписывай и не удаляй неизменяемые receipts, отрицательные доказательства и записи журнала решений. Новое состояние — отдельное актуальное утверждение со ссылкой на историю; пересмотр решения в журнале — новая запись со ссылкой на прежнюю. Это не разрешает удаления других фактов, массовой правки или уплотнения.

## Учет и вход

Цель, ограничения, сделанное, проверки, блокеры и следующий шаг веди в одном Markdown-владельце `docs/backlog/`: найди/создай до работы, по готовности перенеси в `docs/done/` с тем же ID. Todo файл не заменяет.

`description` обязателен: одна строка о вопросе, по которому ищут факт. Он входит в эмбеддинг вместе с телом и помогает читать индекс.

Нативную автопамять проверь новой сессией до признания подключенной; глобальную подключают отдельно. До проверки адаптера явно читай и пиши `.AI/memory/` — общий файловый источник.
