# Структура учебного курса

```text
.
├── Лекции/                # Стенограммы лекций
│   └── NN-<тема>/
│       ├── transcript.md    # Стенограмма
│       └── slides/          # Слайды (если есть)
├── Конспекты/                   # Конспекты (см. lecture-notes.md)
│   └── NN-<тема>.md
├── Домашки/                # Домашние задания (см. homework.md)
│   └── NN-<тема>/
├── Источники/              # Книги, статьи, ссылки, шпаргалки
│   ├── books.md
│   └── links.md
└── docs/                    # Постоянная общая документация
    └── syllabus.md          # Программа курса, дедлайны, требования
```

## Правила

- Один курс - один проект. Если несколько курсов - разные репо или подпапки `<курс>/`.
- Стенограммы не редактируются - только конспекты.
- `Источники/` пополняется по мере того, как лектор упоминает источники.
- Финальные проекты/работы - в `Домашки/final/` или `final-project/`.
